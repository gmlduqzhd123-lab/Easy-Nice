성적 일람표 가리기와
나이스 자동입력

학생 이름과 학교명을 ○로 가린 일람표를 이 페이지에서 바로 만들 수 있어요. 파일은 인터넷으로 보내지 않고 이 브라우저 안에서만 처리돼요.

일람표 마스킹 xlsx · hwpx · hwp 파일을 끌어다 놓으면 바로 처리 자동입력 프로그램 엑셀 내용을 나이스 입력칸에 차례로 붙여넣기 (Windows)

일람표 마스킹

"성명"이나 "이름" 열에 있는 학생 이름을 문서 전체에서 ○로 바꿔요. 학교명, "담임: ○○○" 같은 교사 이름, 작성자 정보, 미리보기도 함께 정리해요. 원본 파일은 바뀌지 않아요.

xlsx · hwpx · hwp 파일을 여기로 끌어다 놓거나

파일을 고르면 바로 처리해요.

    🔒 이 페이지는 보안 정책(CSP)으로 외부 전송이 막혀 있어서, 파일이 어디로도 업로드되지 않아요. 그래도 공유하기 전에 결과 파일을 꼭 직접 열어 확인하세요. 문서 안 그림 속 글자와 엑셀 시트 이름은 바꾸지 않아요.

    자동입력 프로그램 v{{VERSION}} · Windows 10/11

    다른 창에 키를 대신 눌러 주는 기능은 브라우저에서 할 수 없어서, 자동입력은 설치형 프로그램으로 제공해요. 설치한 프로그램에서도 마스킹을 쓸 수 있고, 새 버전이 나오면 자동으로 업데이트돼요.

    설치 파일 받기 모든 버전 보기

    아직 배포 주소가 설정되지 않았어요.

    설치

    1. 받은 neis-input-helper-setup.exe를 실행해요.
    2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러요. (코드 서명이 없는 프로그램이라 뜨는 안내예요)

    사용

    1. 엑셀에서 입력할 열 하나를 학생 순서대로 복사 → 클립보드에서 불러오기
    2. 전출 학생처럼 넘어갈 줄은 건너뛰기 체크
    3. 시작 → 대기 시간 안에 나이스의 첫 입력칸 클릭
    4. 멈추려면 F8. 멈춘 번호부터 이어서 할 수 있어요.

    입력이 끝나면 나이스에서 저장하기 전에 내용을 꼭 확인하세요.

    나이스 입력 도우미 v{{VERSION}} · 나이스(NEIS)와 관련 없는 개인 제작 도구예요.
